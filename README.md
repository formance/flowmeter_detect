# 指针与刻度 DeepLabV3+ 联合分割训练

当前 dev 分支仅保留指针与刻度联合分割的数据准备、训练、评测和模型导出代码。模型输入为裁剪后的表盘 RGB 图，输出背景、指针和刻度短线三个类别。已有部署目录 run/ 和工程外的人工标注工具保持独立。

| 目录 | 内容 |
| --- | --- |
| src/data/ | 复核标注转掩膜，按场景分别划分 7:2:1 后合并 |
| src/common/ | DeepLabV3+、数据加载、损失和评测指标 |
| src/training/ | 单卡/多卡训练、验证、ONNX 导出及运行脚本 |
| tests/ | 数据完整性和模型检查 |
| data/pointer_scale_seg/ | 已整理的联合分割数据集（Git 忽略） |
| weights/ | 本地 ImageNet 编码器预训练权重（Git 忽略） |
| outputs/ | 训练输出（Git 忽略） |

数据仅使用人工确认且未删除的 124 张样本，12 张回收站样本已排除。

| 场景 | 训练 | 验证 | 测试 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| scene01_part | 45 | 13 | 6 | 64 |
| scene02 | 18 | 5 | 3 | 26 |
| scene03 | 24 | 7 | 3 | 34 |
| 合并 | 87 | 25 | 12 | 124 |

按要求分散相邻/相似画面，5 对完全重复图片保持同组。划分依据和逐张清单见数据集 manifest.json。标签为单通道 PNG：0 背景、1 指针、2 刻度；刻度线宽固定为原图 1 像素，交叉熵类别权重为背景 0.2、指针 1、刻度 4。

训练与验证仅统计指针、刻度真值像素的严格召回率，按两类召回率的算术平均值选择模型和早停；背景、多分区域及补边不参与指标计算。

在工程根目录执行 GPU 训练：

```bash
# 复用已下载的 weights/resnet18-f37072fd.pth
bash src/training/train_docker.sh

# 多卡，全局 batch 必须能被 GPU 数量整除
GPUS=0,1 bash src/training/train_docker.sh --batch 8
```

默认使用已有 flowmeter_train:v1.1 镜像，源码和数据以只读方式挂载，输出写入 outputs/。完整操作见 [训练说明](docs/TRAINING.md)。
